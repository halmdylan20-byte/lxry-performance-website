LXRY PERFORMANCE — WEBSITE + ORIGINAL 3D PACKET

This package includes the original WebGL geometry, front and back images embedded directly in model/index.html, and mouse/touch control logic from the uploaded LXRY-3D-Model(1).zip.

RUN LOCALLY:
  cd lxry-website
  python3 -m http.server 8000
  Open http://localhost:8000

DEPLOY: Upload the CONTENTS of lxry-website to Netlify, Vercel, or another static host. Keep model/index.html alongside index.html.

CONTROLS: Drag with mouse or one finger to rotate 360 degrees. Wheel or two-finger pinch to zoom; two fingers also pan. Use Front, Back, Side, Rotate and Zoom buttons. The viewer has a transparent canvas over the black website background.

The shop UI is a prototype and does not process real payments.
